# Дизайн-система «Атлье» — общая база

Единая айдентика для лендинга и приложения. Ниша: мастера (косметология, ногти, хендмейд), маленькие магазины, небольшой бизнес (например, ветклиника) — аудитория с сильным чувством вкуса, но далёкая от технологий. Не должно читаться ни как «ИИ-стартап», ни как типовое wellness-приложение.

## Цвет
- `#FAFAF6` — фон, почти белый, не кремовый
- `#1F2420` — основной текст, тёплый почти-чёрный
- `#4A2545` — слива, айдентика бренда. Используется для логотипа, активного состояния навигации (мягкой заливкой, не сплошной), одного акцентного блока на экране. Никогда не означает статус.
- `#1F5C42` — изумруд, единственный цвет подтверждения. Означает только «готово / да, верно»: галочки на пройденных этапах, кнопка «Утвердить». Больше нигде не используется.
- `#EFE3EB` — мягкий сливовый тон для фонов превью-карточек
- `#B8A98C` — тёплый охра-беж, второй нейтральный тон для фото-плейсхолдеров
- `#a3a89c` — приглушённый серо-оливковый для второстепенных действий и неактивных пунктов

Правило: на одном экране — не больше одного цветного смыслового акцента одновременно (кроме нейтральных/фото-плейсхолдеров). Слива и изумруд никогда не конкурируют за одно и то же значение.

## Типографика
- Заголовки — контрастный editorial-serif с характером (в духе Fraunces/Canela), не системный шрифт
- Текст и интерфейс — гуманистический sans, тёплый, читаемый
- Только sentence case. Никаких ALL CAPS-лейблов нигде — ни на лендинге, ни в приложении

## Общие принципы
- Разделение через отступы, а не рамки. Не более одного уровня вложенности карточек
- Один смелый акцент на экран, дальше — спокойно (см. правило restraint из frontend-design skill)
- Копирайт — простым человеческим языком, без маркетингового и айтишного жаргона внутри рабочего инструмента
- Кнопки — глагол первым, sentence case, без лишней пунктуации

## Бриф 1 — Лендинг

**Кто читает:** мастер, который ещё не пробовал продукт, листает с телефона. Первая задача — доказать «мы понимаем твой вкус», и только потом — что это ИИ-инструмент.

**Hero:** не абстрактная метрика, а заголовок + живой пример сгенерированного поста рядом — доказательство с первого экрана, а не обещание.

**Layout:** editorial-асимметрия (крупный заголовок сдвинут, контент — сбоку), не карточная SaaS-сетка.

**Движение:** GSAP по минимуму — одно оркестрованное появление hero-блока при загрузке, мягкое проявление превью-карточек при скролле. Никакого scroll-hijacking, никакого Three.js/3D.

**Тон текста:** тёплый, конкретный, обращение на «вы». Формулировки о выгоде — ок именно здесь (это точка продажи), но без корпоративных штампов.

## Бриф 2 — Фронтенд приложения

**Кто использует:** тот же мастер, но уже внутри инструмента, делает реальную работу. Здесь важна скорость и ясность, а не убеждение.

**Структура:** сайдбар с этапами конвейера по порядку —
ЦА и позиционирование → распаковка эксперта → анализ аккаунта → анализ конкурентов → упаковка аккаунта → контент-план → посты → изображения → рилсы.
Пройденные этапы — изумрудная галочка, текущий — мягкая сливовая подсветка пункта, будущие — нейтральный серый.

**Карточки результатов (посты/изображения/рилсы):** без рамок, разделение через отступ (24px между карточками). Превью — скруглённый блок (10px), подпись, ниже — текстовые действия «Утвердить» (изумруд) и «Переделать» (нейтральный серый), без кнопок-пилюль.

**Экран распаковки эксперта / онбординга:** смешанный формат — сверху пара коротких полей (специализация, город и т.п.), ниже — открытые вопросы в виде отдельной приподнятой карточки-диалога с аватаром, а не строкой формы. Вопросы формулируются простым языком («что клиентки говорят о вас после визита»), не маркетинговыми терминами.

**Чего избегать (по антипримеру из ветеринарного макета):**
- вложенных рамок «карточка в карточке в карточке»
- разноцветной раскраски однотипных показателей без смысловой причины
- ALL CAPS-лейблов
- маркетинговых формулировок внутри рабочего интерфейса («экономия 80% времени» — уместно на лендинге, не в самом инструменте)
