# Нейро-СММ Ассистент

Веб-сервис для мелкого бизнеса и частных экспертов: анализирует их соцсети и соцсети конкурентов, распаковывает целевую аудиторию и экспертность, и на основе этого генерирует контент-план и демо-контент (посты, картинки, сценарий Reels) — без типичных нейросетевых шаблонов («нейрослопа»).

Сейчас проект на учебном/некоммерческом этапе, разрабатывается как MVP.

## Как это работает (коротко)

1. **Онбординг** — эксперт даёт ссылки на свои соцсети и на 2–3 конкурентов, отвечает на короткий опросник, при желании прикладывает медиа-референсы.
2. **Глубокая аналитика** — агенты на базе LLM распаковывают целевую аудиторию и экспертность (метод, принципы, табу), анализируют свой аккаунт и конкурентов.
3. **Стратегия и планирование** — аудит профиля, контент-план на 2 недели (темы и заголовки по дням и платформам).
4. **Демо-контент** — из всего плана полностью генерируются 3 позиции для демонстрации качества: пост Telegram, пост ВК, сценарий Reels для ВК (текст + изображение/видео), с подтверждением пользователя перед каждой платной медиа-генерацией.

Полная архитектура, пайплайн агентов, обоснование технических решений — в [`docs/project-specification.md`](docs/project-specification.md).

## Стек

- **Backend:** Node.js + Express, TypeScript, SQLite (Drizzle ORM).
- **Frontend:** React + Vite, TypeScript.
- **LLM:** OpenRouter API — Claude Sonnet 5 (распаковка ЦА и экспертности), DeepSeek V4 (остальные агенты).
- **Медиа-генерация:** собственный MCP-сервер [`smm-mcp`](smm-mcp/README.md) (`generate_image`/`generate_video` через OpenRouter).
- **Уведомления оператору:** Telegram-бот (long polling).

## Структура репозитория

```
/backend        — Express API, TypeScript, SQLite/Drizzle
/frontend       — React/Vite: лендинг, онбординг, дашборд, контент-хаб, экспорт
/smm-mcp        — MCP-сервер медиа-генерации, отдельный npm-пакет
/prompts        — системные промпты агентов (распаковка ЦА, распаковка экспертности)
/docs           — спецификация проекта, сториборд лендинга
```
